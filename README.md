# Introduction to Databases

SQL and MySQL exercises for creating and working with a simple bookstore database.

## Contents

- **alx_book_store.sql** — schema and seed/setup work for the bookstore database
- **task_2.sql** through **task_6.sql** — SQL practice tasks
- **MySQLServer.py** — a Python/MySQL connection example

## Getting started

Run the SQL files in a local MySQL environment. Configure database credentials locally through environment variables or a private configuration file—never commit credentials to the repository.

## Purpose

This repository demonstrates foundational database skills: schema creation, SQL queries, and connecting a Python application to MySQL.
